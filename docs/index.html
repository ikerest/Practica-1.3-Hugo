Sitio web de Iker Estebaranz

Sitio web personal desarrollado para las prácticas P1.2 y P1.3 de Implantación de Aplicaciones Web (IAW) en 2º de ASIR.

La web está generada de forma estática con Hugo y publicada tanto en servidor local Nginx (P1.2) como en Internet a través de GitHub Pages sirviendo el directorio html/ de la rama main (P1.3). Al entregarse como HTML y CSS estáticos precompilados, ofrece máxima seguridad, velocidad de carga y cero dependencias de bases de datos en producción.

Secciones

  • Blog: Notas sobre despliegue, páginas web estáticas en GitHub Pages, configuración de servidores y herramientas web.
  • Sobre mí: Información sobre mi perfil en ASIR y administración de sistemas.
  • Contacto: Vías para comunicarse conmigo.
